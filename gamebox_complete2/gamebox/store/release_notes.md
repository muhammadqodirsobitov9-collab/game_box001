# Release Notes

## v1.0.0 — Initial release

- 50 mini-games across Arcade, Puzzle, Brain, and Casual categories
- XP, levels, coins, and 8 achievements
- Fully offline — no account, no ads, no internet required to play
- Dark and light themes
- English, Russian, and Uzbek language support
- Download additional game packages from within the app
- Admin Panel for publishing custom content packs
- Local high-score leaderboard per game
- Sound and haptic feedback
